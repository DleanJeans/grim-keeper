# Sushi Buffet: Character info tokens

Every Townsfolk, Outsider, Minion and Demon in the official catalog, with the info tokens the Character info table shows for it.

Legend: 👤 player · 🎭 character · #️⃣ number · ☑️ choice · ✏️ free text. ⚠️ **Generic** means there is no template yet, so it falls back to Player + Info. **None** means the character is hidden from the table.

- **Townsfolk:** 69 characters, 0 generic, 10 with no tokens
- **Outsiders:** 23 characters, 0 generic, 14 with no tokens
- **Minions:** 27 characters, 0 generic, 9 with no tokens
- **Demons:** 19 characters, 0 generic, 3 with no tokens
